+ Easy memory

Input = data goes IN to child component : បោះតម្លៃពី​ Parent to Child 
Parent gives something to child. 

Output = message/event comes OUT from child component : រង់ចាំមាន ព្រឹតិការអីកើតឡើង វានឹង បោះតម្លៃនឹងទៅក្នុងវិញ
Child tells parent something happened. កូនអ្នកប្រាប់ទៅ Parent 

-----------------------------


Parent = bigger component
Child  = smaller component used inside parent

Ex

AppComponent = parent
ProductComponent = child

យើងយក ProductComponent ដាក់ចូល AppComponent


Easy memory :

Parent holds child.
Parent uses child.
Child lives inside parent.
