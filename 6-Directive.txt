2- ngSwitch is used to show different HTML elements based on a condition.


Basic Syntax:

<div [ngSwitch]="value">
  <div *ngSwitchCase="'A'">Case A</div>
  <div *ngSwitchCase="'B'">Case B</div>
  <div *ngSwitchDefault>Default Case</div>
</div>

- TypeScript

export class AppComponent {
  role = 'admin';
}

- HTML

<div [ngSwitch]="role">

  <p *ngSwitchCase="'admin'">
    Welcome Admin
  </p>

  <p *ngSwitchCase="'user'">
    Welcome User
  </p>

  <p *ngSwitchCase="'guest'">
    Welcome Guest
  </p>

  <p *ngSwitchDefault>
    Unknown Role
  </p>

</div>

-------------

| Old Syntax         | New Angular 17+ |
| ------------------ | --------------- |
| `ngSwitch`         | `@switch`       |
| `*ngSwitchCase`    | `@case`         |
| `*ngSwitchDefault` | `@default`      |



3- ngFor : looping 

basic syntax:

<div *ngFor="let item of items">
  {{ item }}
</div>

- TS

export class AppComponent {
  fruits = ['Apple', 'Banana', 'Orange'];
}

- html 

<ul>
  <li *ngFor="let fruit of fruits">
    {{ fruit }}
  </li>
</ul>


| Old Syntax      | Angular 17+      |
| --------------- | ---------------- |
| `*ngFor`        | `@for`           |
| `let i = index` | `let i = $index` |
| `trackBy`       | `track`          |


- TS

@for (emp of employees; track emp.id) {
  <p>{{ emp.name }}</p>
}

- HTML 

@for (emp of employees; track emp.id) {
  <p>{{ emp.name }}</p>
}

4- ngNonBindable 

prevent Angular from compiling or evaluating expressions inside an HTML element.


<p ngNonBindable>
  {{ message }}
</p>


==> output : {{ message }}



5-ngStyle

ngStyle in Angular is used to apply CSS styles dynamically to an HTML element.

Syntax : 

<div [ngStyle]="{'property':'value'}">
  Content
</div>

Ex1:

HTML 

<p [ngStyle]="{'color':'red'}">
  Hello Angular
</p>

Output

Text color becomes red.

Ex2:


Dynamic Style Using Variable: 

- TS 

export class AppComponent {
  textColor = 'blue';
}

- HTML

<p [ngStyle]="{'color': textColor}">
  Dynamic Color
</p>
